# Video App (Mini Project)

### 🛠 Features:
- Points on video watch (5 per video)
- One download per day unless premium
- Razorpay test payment (optional)
- Theme changes by time + region
- OTP via email or mobile (region-based)

### 🚀 Setup:
1. Clone or download the project.
2. Run `npm install`.
3. Add your Razorpay test keys in `server.js` (optional).
4. Run `node server.js`.
5. Open `http://localhost:3000` in your browser.

🌍 Uses `ipapi.co` for location detection.
